# Acidgoblin Tripper

A touch-driven acid trip in a browser tab. Built from 10 psychedelic Acid Goblin landscape pieces.

Touch the screen. Hold and drag to melt a little kaleidoscope pocket into being; more fingers, more madness. Let go and it cools back to the plain, pretty artwork. Each finger also drives its own detuned acid-synth voice (TB-303-style, Web Audio): position controls filter cutoff and pitch, drag speed controls wobble and distortion.

## Running it

No build, no server, no install. Download both files and open `index.html` in a browser (Chrome/Edge/Firefox with WebGL). Works via a plain double-click.

- `index.html` -- the app
- `bg-data.js` -- the 10 background images, embedded as base64 (keep it next to `index.html`)

Best on a touchscreen, but works with a mouse too.
